# 기존 합성 프로토타입 사용 안내

이 문서는 앱을 처음 여는 단계부터 합성 프로젝트를 설정하고, 에피소드 콘티와 이미지 초안을 검토한 다음, 작업 기록을 백업하고 복구하는 순서로 설명합니다.

> **2026-10-14 새 작업 화면:** D-0035로 구현을 재개했습니다. 현재 기본 화면의 [작업 공간 안내](studio-workspace-guide.md)와 [검증 기록](studio-implementation-validation.md)을 먼저 읽어 주세요. 아래 화면·명령은 `?legacy=1`의 기존 Stage 01–05 합성 프로토타입에 적용됩니다. 기존 v1 백업에 새 studio v2 작업·체크포인트가 포함되지는 않습니다. PC 이동의 완전한 v2 백업·복원은 후속 통합 대상입니다.

> **현재는 플랫폼 검증용 합성 모드입니다.** 실제 계정·캐릭터·레퍼런스·에피소드 자료를 입력하지 마세요. 가상의 프로젝트 이름, 주인공, 이야기와 테스트 이미지만 사용하세요. 화면에 `SYNTHETIC ONLY`라고 표시되며, 생성되는 이야기 제안과 그림은 외부 AI를 부르지 않는 규칙 기반 MOCK 결과입니다. 이 버전은 실제 작품을 만들거나 게시하는 단계가 아닙니다.

## 1. 앱 시작하기

### 이 PC에서 실행

바탕화면의 **Toon Studio** 바로가기를 실행합니다. 로컬 서비스와 기본 브라우저가 열립니다. 브라우저 주소는 `http://127.0.0.1:8765`입니다. 이 주소는 이 PC 안에서만 접속할 수 있고, 앱 자체는 PC 간 원격 접속이나 클라우드 동기화를 제공하지 않습니다. 다른 PC에서는 저장소를 Git으로 가져와 앱을 별도 설치해 로컬 실행할 수 있습니다.

앱이 이미 실행 중이면 바로가기를 다시 열어도 새 서버를 만들지 않고 브라우저에서 기존 앱을 엽니다. 브라우저 탭을 닫아도 앱 서비스는 계속 실행되므로, 작업을 끝낸 뒤 종료하려면 저장소의 `Stop-ToonStudio.cmd`를 실행하세요. 자료는 앱을 닫거나 PC를 다시 시작해도 로컬에 남습니다.

### 처음 설치하거나 다시 설치할 때

기존 검증 기록에는 앱과 바로가기 설치가 포함되어 있습니다. 다른 PC에서 작업하려면 저장소의 검토된 동일 커밋 또는 릴리스를 가져오고 앱을 별도 설치합니다. 기존 프로젝트 데이터는 앱의 지원 백업을 내보내 새 PC에서 복구합니다. 현재 앱의 DB와 레퍼런스/생성 파일은 코드 저장소와 별개로 각 PC에 남으므로, Git으로 코드만 가져오거나 이 설치 명령을 실행해도 작업 데이터까지 이동되지는 않습니다. 설치가 초기화된 경우에도 해당 PC의 저장소 폴더 `toon_generator`에서 PowerShell을 열고 다음을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-ToonStudio.ps1 -CreateDesktopShortcut
```

설치할 때 Python 패키지와 화면 빌드를 준비하므로 인터넷이 필요할 수 있습니다. 설치한 뒤의 합성 작업은 인터넷이나 외부 이미지 공급자 없이 진행됩니다. 기존 검증에서 확인된 실행 환경은 Windows, Python 3.12, Node 24, pnpm 11입니다. 이 기록은 다른 PC의 확정 요구 사양이 아닙니다. 사용할 PC의 OS·런타임 호환성과 CPU/RAM/GPU/VRAM·저장 공간은 별도로 확인하며, 이미지 생성 사양을 현 PC에서 추론하지 않습니다.

### Git으로 가져오는 것과 별도로 옮기는 것

| 구분 | 이동 방법과 범위 |
|---|---|
| 앱·명세·설치 자료 | Git으로 코드, 문서, 스키마, 합성 fixture, 설치 스크립트, 의존성 버전/잠금 파일, 비밀정보 없는 설정 템플릿을 가져옵니다. 템플릿은 저장소에 정의된 것만 사용합니다. |
| 프로젝트 작업 데이터 | PC마다 별도로 저장합니다. DB·프로젝트 기록·레퍼런스 복사본·생성 이미지·검토 기록은 Git에 자동 포함하지 않으며, 프로젝트별 백업 파일로 옮깁니다. |
| PC 환경과 비밀정보 | 가상환경·설치 패키지·화면 빌드·바로가기는 목적 PC에서 다시 준비합니다. API 키·토큰·개인 설정·모델 가중치/캐시는 Git과 프로젝트 백업에 넣지 않습니다. 모델 설치와 비밀정보 설정은 별도 범위입니다. |

저장소는 상위 작업 폴더 아래의 `toon_generator`가 Git 루트입니다. 설치 자료에는 개인 계정명이나 원래 PC의 절대 경로를 고정하지 않습니다. 작업 데이터 기본 경로인 `%LOCALAPPDATA%\ToonStudio`는 해당 PC의 Windows 계정 기준으로 해석됩니다. 저장소 위치, 데이터 기본 위치, 매번 선택하는 백업 목적지는 서로 다릅니다. 데이터/모델 경로를 자유롭게 바꾸는 설정은 이 명세만으로 추가되지 않습니다.

현재 설치 스크립트는 Python 3.12 이상을 찾고, 화면 빌드가 필요하면 Node 22.12 이상을 검사합니다. Codex 번들 런타임은 선택적 탐색 경로이며 다른 PC의 필수 조건은 아닙니다. 이 최소 검사만으로 모든 버전의 호환성을 보장하지 않습니다. 저장소의 의존성 버전·잠금 파일을 유지하고, 대상 PC에서 검증한 런타임과 설치 결과를 기록해야 합니다. 기존 바로가기는 설치 스크립트가 자동 덮어쓰지 않으므로 저장소를 옮긴 뒤에는 대상 경로를 확인하세요. 자세한 재현 조건은 [기술 기준](platform-technical-baseline.md#11-installation-reproducibility-and-machine-specific-paths)에 있습니다.

## 2. 첫 합성 프로젝트 만들기

처음 열면 시작 화면에서 **합성 프로젝트로 시작**을 누릅니다. 왼쪽 프로젝트 목록의 **프로젝트 만들기**로 시작해도 됩니다. 준비된 가상의 프로젝트 설정이 열리며, 프로젝트 이름·컨셉·주인공·시리즈 방향·독자·톤·제외 요소·허용 형식을 확인할 수 있습니다.

예시 설정으로 시작해도 되고, 흐름을 익히기 위해 이 항목들을 가상의 값으로 바꿔도 됩니다. **설정 수정 → 새 버전 저장**을 누르면 새 설정 버전이 생깁니다. 저장 후에는 아래의 설정 검토 세 가지를 현재 버전에서 다시 해야 합니다.

| 검토 | 확인할 내용 |
|---|---|
| **RG · 레퍼런스** | 자료의 출처·사용 근거와 복제하지 않을 요소 |
| **CG · 캐릭터** | 반복 등장할 주인공의 외형과 성격 |
| **SG · 시리즈** | 이야기 방향·독자·톤·제외 요소 |

각 검토에서 설정을 읽고 **승인**, **수정 요청**, **반려** 중 하나를 선택한 뒤 결정 기록 버튼을 누릅니다. 필요하면 메모를 덧붙입니다. 결정은 그때 검토한 버전에만 적용됩니다. 이 버전에서는 가상 설정의 검토 흐름을 연습하기 위한 기록이며, 실제 작품의 승인으로 볼 수 없습니다.

### 합성 레퍼런스 시험하기

레퍼런스를 시험하고 싶다면 **로컬 자료 추가**를 누르고 본인이 만든 가상 테스트 파일만 선택합니다. 허용 형식은 PNG, JPEG, WebP, PDF이며 파일은 20MB 이하여야 합니다. 출처와 사용 근거를 적고, **실제 프로젝트 자료가 아닌 합성 테스트 자료**와 **프로젝트에 복사하고 계속 보관할 수 있는 자료**를 체크한 다음 복사합니다. 원본 파일은 바뀌지 않고 프로젝트 안에 복사본이 보관됩니다. 자료 없이도 나머지 합성 흐름을 진행할 수 있습니다.

## 3. 에피소드 입력과 콘티 만들기

프로젝트 화면의 **에피소드 만들기** 또는 **에피소드 입력**을 누릅니다. 다음을 입력합니다.

1. 가상의 에피소드 제목을 정합니다.
2. **짧은 소재**를 고르면 소재를 바탕으로 세 가지 규칙 기반 이야기 방향이 나옵니다. **구체적인 스토리**를 고르면 입력 원문을 보존한 채 장면별 콘티를 준비합니다. 두 경우 모두 합성 테스트 소재 체크가 필요합니다.
3. 형식을 **1컷** 또는 **다컷**으로 고릅니다. 다컷은 2–8컷을 지원합니다. 요청한 형식과 참고 형식이 다르거나 형식을 정하지 않았으면, 사용할 컷 구성을 직접 확인해야 다음으로 갈 수 있습니다.
4. 구체적인 스토리에서 대사와 컷 설명을 고칠 수 있게 하려면 **대사와 컷 설명의 편집을 허용합니다**를 선택합니다.
5. **에피소드 만들기**를 누릅니다.

짧은 소재를 입력했다면 세 가지 제안 중 이야기 방향을 선택하고 **Level 1 콘티 만들기**를 누릅니다. 구체적인 스토리는 입력한 원문이 별도로 보관됩니다. 콘티에서 **처음 입력한 소재 / 스토리**를 눌러 원문을 다시 확인할 수 있습니다.

콘티 보드에는 컷별 러프 그림과 컷 설명·대사·구도·연속성이 나타납니다. **컷 설명 수정**을 눌러 내용을 고친 뒤 **수정 저장**을 눌러 새 버전을 만듭니다. 저장 전에는 수정 내용이 임시 상태로 남습니다. 콘티를 저장하거나 바꾸면 이전 버전은 기록에 남고, 새 버전은 다시 검토해야 합니다.

### G2 콘티 검토

모든 컷의 흐름과 대사를 확인한 뒤 **G2 · 콘티 검토**에서 현재 콘티 버전을 승인하거나 수정 요청·반려합니다. 검토 결정과 메모는 버전에 연결됩니다. 초안 생성 버튼은 **현재 콘티 버전이 승인된 뒤** 사용할 수 있습니다. 콘티를 수정한 뒤에는 그 새 버전에 다시 G2 검토가 필요합니다.

## 4. 이미지 초안 선택과 G3 검토

G2 승인 후 **합성 초안 생성**을 누릅니다. 각 컷마다 MOCK 이미지 후보 두 개와 전체 배치 미리보기가 만들어집니다. 이 그림은 합성 검사용 이미지이며, 실제 AI 생성 결과가 아닙니다.

1. 각 컷에서 후보 이미지를 눌러 선택합니다. 선택을 바꾸면 새 초안 실행 버전으로 기록됩니다.
2. **전체 배치 보기**를 눌러 선택된 컷을 한 화면에서 확인합니다. 다시 누르면 컷별 후보 보기로 돌아옵니다.
3. 특정 컷을 다시 만들고 싶다면 해당 컷 체크박스를 선택하고 **선택 N컷 재생성**을 누릅니다. 선택한 컷만 바뀌며, 기존 초안은 버전 기록에 유지됩니다.
4. 콘티를 고쳤다면 이전 초안은 참고 기록으로 남습니다. 새 콘티에 G2 승인을 받고 **새 콘티로 전체 생성**을 눌러 새 초안 묶음을 만듭니다.
5. 모든 컷에서 후보 하나씩 선택해야 **G3 · 초안 검토**에서 승인을 선택할 수 있습니다. 전체 배치를 살펴보고 승인·수정 요청·반려 중 하나를 기록합니다.

G3까지 마치면 이번 MVP의 검토 흐름이 끝납니다. 수작업 보정, 최종 결과물 내보내기, 게시 기능은 포함하지 않습니다.

## 5. 버전과 검토 기록 보기

왼쪽에서 **버전 · 검토 기록**을 엽니다. 여기에서 다음 기록을 살펴볼 수 있습니다.

- **버전 기록:** 설정·콘티·이미지 산출물을 보고 이전 버전과 JSON 기록을 확인합니다.
- **사람 검토:** RG·CG·SG·G2·G3에서 남긴 승인·수정 요청·반려와 메모를 확인합니다.
- **작업 활동:** 수정, 선택, 생성, 백업과 복구 같은 작업 이력을 확인합니다.

수정하거나 다시 생성한 결과는 새 버전으로 추가됩니다. 이전 버전과 기록을 자동으로 삭제하지 않으며, 앱 안에 프로젝트 삭제 기능은 없습니다.

## 6. 백업하고 복구하기

왼쪽의 **백업 · 복구**를 엽니다. 백업은 현재 선택된 프로젝트 하나를 대상으로 하며, 설정·참고 자료의 출처 기록·에피소드·이미지·버전·검토·작업 기록을 담습니다.

### 백업 내보내기

1. **암호화 없이** 또는 **암호화 사용**을 선택합니다.
2. 암호화 없이 보관하면 파일을 가진 사람이 내용을 읽을 수 있습니다. 화면의 안내를 확인하고 체크해야 합니다.
3. 암호화하려면 암호문구를 입력하거나 **긴 암호문구 생성**을 누릅니다. 20자 이상의 길고 고유한 문구를 권장합니다. 문구를 잃으면 복구할 수 없으므로 별도로 보관했음을 체크합니다.
4. **저장 위치 선택하고 내보내기**를 눌러 파일을 저장합니다. 브라우저에 따라 브라우저 저장 창이나 Windows 저장 위치 창이 열립니다. 창에서 취소하면 백업을 내보내지 않습니다.

암호화하지 않은 파일은 `.toonbackup`, 암호화한 파일은 `.toonbackup.age`입니다. PC 밖으로 옮길 백업에는 암호화를 권장합니다. 앱 암호문구는 PC에 저장되지 않습니다.

### 별도 복사본으로 복구

1. **백업 파일 선택**에서 `.toonbackup` 또는 `.toonbackup.age` 파일을 고릅니다.
2. `.age` 파일이면 백업을 만들 때 사용한 암호문구를 입력합니다.
3. **별도 복사본으로 복구**를 누릅니다.

복구 결과는 새 `project_id`를 받는 별도 프로젝트입니다. 원본은 유지됩니다. 복구 전에 파일·체크섬·형식 등을 검사하며, 과거 검토 기록은 보존하지만 복구 프로젝트의 현재 단계 승인을 대신하지 않습니다. 가상 합성 프로젝트에서 이 흐름을 확인하세요.

### 다른 PC로 작업 데이터 옮기기

다음은 기존 백업·복구 경로를 사용하는 이동 절차입니다. 추가 구현이나 실제 자료 사용을 허가하는 절차는 아닙니다.

1. 목적 PC에서 가져올 저장소 커밋/앱 버전과 백업 형식·스키마 호환성을 확인하고 별도 로컬 설치를 준비합니다. Git을 가져와도 기존 프로젝트는 나타나지 않습니다.
2. 원본 PC에서 옮길 프로젝트 하나를 선택해 백업을 내보냅니다. 프로젝트가 여러 개라면 각각 내보냅니다. PC 밖으로 옮기는 파일에는 암호화를 권장하며, 선택은 매번 사용자가 합니다.
3. 사용자가 정한 매체나 위치로 백업 파일을 옮깁니다. 암호문구는 백업과 별도로 보관하고, API 키나 토큰을 파일에 추가하지 않습니다.
4. 목적 PC 앱의 **백업 · 복구**에서 파일을 선택해 **별도 복사본으로 복구**합니다. 기존 프로젝트를 덮어쓰지 않고 새 ID를 만들며 원본 프로젝트/백업의 출처를 유지합니다. 지원하지 않는 형식, 파일 손상 또는 잘못된 암호문구는 복구를 막습니다.
5. 복구한 설정, 자료·이미지, 버전 관계와 과거 검토 기록을 확인합니다. 과거 승인은 역사 기록으로 남으므로 새 복사본의 현재 단계는 다시 사람의 검토가 필요합니다. 확인이 끝날 때까지 원본과 백업을 보관하세요.

**추천 운영 방식 · 사용자 선택 미결:** 프로젝트마다 한 작업 기간에는 한 PC의 복사본을 작업본으로 정하고, 이동 시 저장소/앱 버전·백업 ID·원본/복구 프로젝트 ID와 확인 결과를 기록합니다. 두 PC에서 따로 수정했다면 두 복사본을 보존하고 사용자가 이어갈 작업본을 선택합니다. 자동 병합이나 최신본 자동 선택은 제공하지 않습니다. 다시 원래 PC로 옮겨도 백업·복구로 또 다른 복사본이 생깁니다. 별도 이동 기록 화면이나 기능이 구현되었다는 뜻은 아닙니다.

백업에는 프로젝트가 보관한 레퍼런스 복사본이 포함됩니다. 외부 원본 파일, 전체 PC 환경, 모델 가중치·캐시와 비밀정보까지 옮기는 전체 PC 백업은 아닙니다. 모델 파일의 설치/이동 조건은 대상 PC와 모델의 버전·사용 조건·체크섬·경로를 정한 뒤 별도로 검토합니다.

## 7. 저장 위치와 사용 범위

작업 자료는 각 PC의 `%LOCALAPPDATA%\ToonStudio`에 저장됩니다. 앱에는 별도 비밀번호가 없고 Windows 로그인 계정 권한을 사용합니다. 실행 중인 데이터베이스를 클라우드 동기화 폴더에 옮기지 마세요. DB 파일만 복사하거나 두 PC가 같은 활성 DB/자료 폴더를 사용하도록 연결하는 방식은 지원 이동 경로가 아닙니다. 다른 PC에서 작업하려면 별도 설치 후 내보낸 프로젝트 백업 파일을 옮겨 복구합니다. 각 PC의 `127.0.0.1:8765`는 그 PC의 앱을 가리키며, 실시간 동기화나 다른 PC 앱에 대한 원격 접속은 지원하지 않습니다.

| 항목 | 현재 지원 범위 |
|---|---|
| 에피소드 | 1–8컷 |
| 레퍼런스 시험 파일 | PNG, JPEG, WebP, PDF, 최대 20MB |
| 프로젝트 백업 | 최대 256MB |
| 앱 접속 | 이 PC의 `127.0.0.1:8765` |
| 자동 삭제 | 없음. 프로젝트 삭제 기능도 제공하지 않음 |

지원 범위나 파일이 맞지 않으면 오류가 표시됩니다. 제한을 넘는 파일은 나누거나 지원 형식으로 준비하세요.

## 8. 문제가 생겼을 때

| 상황 | 확인할 내용 |
|---|---|
| 콘티 만들기 버튼을 눌러도 진행되지 않음 | 이야기 방향을 선택했는지, 컷 형식이 확인됐는지 살펴보세요. |
| 합성 초안 생성이 비활성화됨 | 현재 콘티 버전에 G2 승인이 기록됐는지 확인하세요. 수정 후라면 새 버전을 다시 검토해야 합니다. |
| G3 승인이 비활성화됨 | 각 컷에서 후보 하나씩 선택했는지 확인하세요. 수정 요청·반려는 먼저 기록할 수 있습니다. |
| 이전 콘티의 초안이라고 표시됨 | 현재 콘티를 G2에서 승인한 뒤 **새 콘티로 전체 생성**을 누르세요. |
| 앱에 연결할 수 없음 | 바탕화면 바로가기를 다시 실행하고 브라우저를 새로고침하세요. 다른 프로그램을 강제 종료하지 마세요. |
| 암호화 백업 복구가 안 됨 | 사용한 암호문구와 `.age` 파일을 다시 확인하세요. 암호문구를 분실한 백업은 복구할 수 없습니다. |

앱 화면의 **제작 흐름 안내**에서도 간단한 단계 설명을 볼 수 있습니다.

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-ToonStudio.ps1 -CreateDesktopShortcut
