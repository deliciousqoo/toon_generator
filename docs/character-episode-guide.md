# 캐릭터로 이야기와 콘티 만들기

기준일: 2026-10-18. D-0039에 따라 확정한 캐릭터 시트를 바탕으로 에피소드를 만든다. 기존 합성 이야기 테스트는 `?storyFixture=1`에 보존한다.

## 진행

1. 캐릭터 시트를 최종 확인한 프로젝트에서 **이야기·콘티**를 연다. 시작할 때 고정한 방향·시트 버전을 확인할 수 있다.
2. 떠오르는 상황이나 감정을 입력한다. 오케스트레이터와 대화하면서 이야기 소재·전할 감정·마무리를 정리한다. 한 번에 필요한 질문 하나씩 받는다.
3. 정리한 의도로 **이야기 초안**을 요청한다. 전개와 마무리를 바로 확인하고 대화로 수정한다. 특정 전개와 **대사만** 등 수정 항목을 고르면 그 밖의 내용을 보존한다.
4. 마음에 드는 이야기의 정확한 버전을 확인한다(G1). 그 뒤 제안된 컷 수·배치를 확인하거나 바꾼다. 이야기 확인 전에 컷 구성을 자동 확정하지 않는다.
5. 확인한 구성으로 장면 구성을 요청한다. 각 컷의 행동·표정·대사·구도·연속성을 살펴보고 필요한 컷이나 항목만 수정한다.
6. 각 컷의 러프 요청을 준비한다. 요청문과 기준 이미지를 이 Codex 대화에 전달해 이미지를 생성하고, 결과를 해당 요청에 가져온다. 앱이 자동 이미지 생성을 실행하지는 않는다.
7. 실제 러프 이미지와 별도 대사를 함께 보며 전체 읽기 흐름을 확인한다. 시각 지시를 바꾼 컷은 그 이미지의 재검토가 필요하다. 대사만 바꾸면 그림을 유지할 수 있다.
8. 모든 컷을 확인한 뒤 현재 콘티를 최종 확인한다(G2). 완료 후에도 수정 단계로 돌아갈 수 있으며 이전 결과와 확인 기록은 남는다.

G1·컷 구성·G2는 별도 결정이다. 글만 있는 장면 구성은 시각 콘티 완료가 아니다. G2는 Stage 05 이미지 초안 생성이나 게시 승인으로 이어지지 않는다.

## 저장과 연결

- 에피소드마다 확정 방향·시트·선택 후보·이미지 체크섬·사람 확인을 고정한다. 새 시트를 기존 에피소드에 몰래 대입하지 않는다. 캐릭터 승인이 달라지면 기존 결과는 읽을 수 있지만 추가 수정·확인은 멈춘다. 새 시트로 작업하려면 새 이야기를 시작한다.
- 이야기 수정은 후속 구성·콘티의 현재 확인을 해제한다. 지정한 컷의 시각 수정은 해당 컷의 현재 러프만 해제하고 다른 컷을 보존한다.
- 러프 요청은 승인 시트와 함께 이미 등록된 가장 가까운 앞 컷 하나를 소품·화풍 참조로 고정한다. 자기 컷의 수정 원본과 앞 컷의 연속성 참조를 구분하며, 실제 생성에 사용한 원본 관계는 ZIP에도 보존한다.
- ChatGPT Pro 연결과 기존 프로젝트별 40회 시도 한도를 공유한다. 이전 캐릭터 대화 호출과 실패 시도도 포함하며 새 이야기를 만들어 한도를 우회하지 않는다. 에피소드별 한도도 40회, 한 대화의 역할 호출은 최대 2회, 역할별 최대 60초다.
- 한도·연결 실패나 불확실한 중단 후 모델을 자동 재호출하지 않는다. 유료 API 전환도 없다. 화면에 남은 입력과 이전 결과를 보고 직접 다음 행동을 정한다.
- 승인 콘티 ZIP은 정확한 이야기·구성·콘티·시트 기준, 이미지와 원본 출처를 담은 산출물 패키지다. 전체 프로젝트의 대화·체크포인트를 복원하는 백업은 아니다.

텍스트 작성자와 독립 검토자는 같은 시트 PNG 원본을 이미지 입력으로 받는다. 역할의 입력과 결과는 LangGraph 및 로컬 SQLite에 보관하고, 사람의 확인은 오케스트레이터가 버전과 함께 기록한다. 이미지의 출처·실제 프롬프트·알 수 없는 모델/시드는 각각 구분한다.

연결 형식은 OpenAI 공식 [구독 연결 제한](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)과 [이미지 입력 안내](https://developers.openai.com/api/docs/guides/images-vision)를 따른다. 구현 계약은 [episode-api.md](contracts/episode-api.md), 실제 수행과 검증 범위는 [구현 검증 기록](studio-implementation-validation.md)을 참고한다.
